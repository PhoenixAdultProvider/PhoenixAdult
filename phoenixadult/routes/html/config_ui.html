Push Logos to Collections

    

      
Sets each Plex collection's clearLogo from a matching cached logo (by name) — the logo
        belongs on the sub-site collection, not every scene. Idempotent: collections already carrying our logo are
        skipped. Plex fetches the image from Local Image Base Address (Images tab), so that must be reachable
        from the Plex server. Manage the logo files at /logos.

      

        
        
        
        
      

      

    


    
Import a Library Into the Cache

    

      
Reads every scene in one Plex movie library and stores it as a provider snapshot (metadata
        plus poster and background art), so content whose site is gone stays servable. Scenes already cached are left
        alone — a stored fresh scrape is never overwritten. Actor headshots are not imported; the people pipeline
        resolves those. Scenes whose site is not in the registry are reported as unresolved and skipped.

      

        
        
      

      

        
        
        
        
        
      

      

    


    
Purge clearLogos from Plex

    

      
Removes provider-supplied clearLogo art from Plex — the applied logo on each item and its
        candidate entry — leaving the logo files on the server untouched. Use this to clear per-scene logos left by
        earlier versions (scenes no longer receive logos). Plex has no API to unset a logo, so this edits the Plex
        database directly. Collection logos set above are left intact.
